You can view the live project here: https://mooraxx1.github.io/currency-exchange-1/

✨ Features
Real-Time Conversion: Updates the exchange rate and total amount instantly as you change inputs.

Live API Integration: Uses the ExchangeRate-API for up-to-date market data.

Responsive UI: A mobile-friendly layout designed with Flexbox.

Dynamic UI Updates: Displays the specific exchange rate for the selected pair (e.g., "1 USD = 0.92 EUR").

🛠️ Built With
HTML5: Semantic structure for the converter interface.

CSS3: Custom styling featuring a modern "Dark Cyan" theme and monospace typography.

JavaScript (ES6+): Fetch API for asynchronous data handling and DOM manipulation.
